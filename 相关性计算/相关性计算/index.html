    相关性计算

    1 服装与人体面相关性计算¶

    查找离每个服装面最近的人体面，这种方法很快速，但是会有一些面错误匹配
    由于褶皱，这些服装面与人体面法线不一致 在袖口和裆部等位置，容易错误匹配

    判断mesh是不是watertight 

    import trimesh

# CLO虚拟模特网格不是watertight，SMPL，STAR网格是watertight

mesh = trimesh.load_mesh("final_star.obj")
print(mesh.is_watertight)

    候选搜索 + 邻域距离约束

    你不应该先独立地为每个服装面确定唯一匹配，再试图修复错误。更好的办法是：每个服装面保留多个候选人体面，然后联合相邻服装面的匹配关系进行选择。

    需要强调的是：不要直接把所有人体面是否相邻作为连续性判断条件，也不要使用固定的绝对距离阈值。 应该让阈值随局部网格尺度变化，并通过样本统计校准。

    1. 读取源人体、目标人体、源服装。
    2. 建立人体顶点或三角形对应关系。
    3. 计算每个人体三角形的局部形变梯度。
    4. 为每个源服装顶点建立人体对应三角形和重心坐标。
    5. 计算人体形变驱动的目标服装初始位置。
    6. 在 PyTorch 中优化目标服装顶点，使服装局部梯度尽量匹配人体局部梯度。
    7. 加入参考形状、平滑、间距和碰撞损失。
    8. 使用 PyTorch3D 可视化、检查并导出目标服装
